# AI 应用开发基础概念
## 1. Token：模型处理文本的基本单位
Token 是文本经过分词器（Tokenizer）处理后，得到的基本单位。模型接收和生成文本，都以 Token 为单位。

* Token 不等于字符，也不等于单词。
* 一个汉字不一定等于一个 Token。
* 同一段文本，使用不同分词器，得到的 Token 数可能不同。

文本如何进入模型：
```text
输入文本
   ↓ Tokenizer 分词
Token ID 序列
   ↓ Embedding 映射
向量序列
   ↓ 模型计算
预测下一个 Token 的概率
   ↓ 选择 Token，继续生成
输出 Token ID 序列
   ↓ 解码
输出文本
```

| 概念 | 是什么 | 作用 |
|---|---|---|
| Token ID | Token 在词表里的整数编号 | 标识一个 Token |
| Embedding | 一组浮点数构成的向量 | 将 Token 表示为模型可计算的向量 |

### 1.1 最大输出token
模型 API 的“最大输出 Token”参数 通常是硬约束。由模型外部的推理服务执行。

模型负责预测下一个 Token；推理服务负责控制生成过程，包括：
- 是否已经生成结束标记（EOS）。
- 是否达到最大输出 Token 数。
- 是否命中停止条件或收到取消请求。
因此，即使模型还想继续生成，服务也可以直接停止，不再执行下一步。
